# NavAlert: Intelligent GPS Route Monitoring

NavAlert is a smartphone-based GPS route monitoring system designed to monitor a traveler's journey in real time and identify deviations from a planned route.

The system uses the smartphone's built-in GPS to track the user's location and continuously monitor the journey. When a significant deviation from the intended route is detected, NavAlert can generate an alert to notify the designated observer.

The project aims to provide a simple, accessible, and low-cost route monitoring solution without requiring dedicated GPS tracking hardware.

## Key Features

- Real-time GPS-based location monitoring
- Planned route monitoring
- Route deviation detection
- Automated deviation alerts
- Smartphone-based operation
- Observer-based journey monitoring
- Cloud-connected monitoring

## Project Objective

The main objective of NavAlert is to develop an intelligent and accessible system that can monitor a journey using a smartphone's GPS and detect when the traveler significantly deviates from the planned route.
